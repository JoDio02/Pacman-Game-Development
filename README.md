# Pacman Game Development (Python)

## Overview
A classic implementation of the Pacman game developed using Python. This project demonstrates core game development principles, including game loops, collision detection, and basic AI for ghost movements.

## Features
- **Dynamic Game Loop**: Smooth animation and movement handling.
- **Collision Logic**: Accurate detection between Pacman, ghosts, and walls.
- **Score System**: Tracks points as Pacman consumes pellets.
- **Modular Design**: Code is cleanly separated into logic, UI, configuration, and utility modules.

## Technologies Used
- **Language**: Python
- **Structure**: Modular Python scripts (`main.py`, `logic.py`, `ui.py`, etc.)

## How to Run
1. Ensure you have Python 3.x installed.
2. Navigate to the project directory.
3. Run `python main.py` to start the game.
