# Pacman Game Development (Java)

## Overview
A classic implementation of the Pacman game developed using Java. This project demonstrates core game development principles, including game loops, collision detection, and basic AI for ghost movements.

## Features
- **Dynamic Game Loop**: Smooth animation and movement handling.
- **Collision Logic**: Accurate detection between Pacman, ghosts, and walls.
- **Score System**: Tracks points as Pacman consumes pellets.
- **Ghost AI**: Basic pathfinding and movement patterns for game entities.

## Technologies Used
- **Language**: Java
- **Graphics**: Java Swing / AWT

## How to Run
1. Ensure you have Java JDK installed.
2. Compile all `.java` files in the source directory.
3. Run the `Main` class to start the game.
